# Sire & Sons Smokehouse website

Plain HTML. Each page is its own file:

- index.html (Home)
- menu.html
- catering.html
- thanksgiving.html
- photos.html
- careers.html

Styles are in css/style.css. Fonts are in fonts/. Logo and images are in img/.

## Common edits

- Thanksgiving form: open thanksgiving.html and put the Tally form ID between the quotes in
  `var TALLY_FORM_ID = "";` (the part after tally.so/r/ in the form's share link).
- Job application form: same line in careers.html.
- Text changes: open the page, find the words, change them.
