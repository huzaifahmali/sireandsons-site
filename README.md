# Sire & Sons Smokehouse website

Plain HTML. Each page is its own file:

- index.html (Home)
- menu.html
- catering.html
- thanksgiving.html
- photos.html
- careers.html

Styles are in css/style.css. Fonts are in fonts/. Logo and images are in img/.

## Common edits

- Holiday order form (Jotform): thanksgiving.html embeds form 263147389067063. For a new form such as
  Christmas, replace that number in the iframe `id`, the iframe `src`, and the `jotformEmbedHandler` line.
- Job application form: same line in careers.html.
- Text changes: open the page, find the words, change them.
