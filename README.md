# Sire & Sons Smokehouse website

Plain HTML. Each page is its own file:

- index.html (Home)
- menu.html
- catering.html
- thanksgiving.html
- photos.html
- careers.html

Styles are in css/style.css. Fonts are in fonts/. Logo and images are in img/.

## Common edits

- Holiday order form (Jotform): thanksgiving.html links to the form at form.jotform.com/263147389067063
  (two buttons). For a new form such as Christmas, replace that address on the page, and update the prices.
  The earlier version that embedded the form is in git history (commit dc741ad).
- Job application form: same line in careers.html.
- Text changes: open the page, find the words, change them.
